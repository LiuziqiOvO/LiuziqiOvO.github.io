# Trash

This directory keeps blog content that should no longer be published but should not be permanently deleted.

When hiding existing posts, pages, or assets, preserve their original relative path under this directory. For example:

```text
source/_posts/old-note.md -> trash/source/_posts/old-note.md
source/_posts/old-note/ -> trash/source/_posts/old-note/
```

Hexo does not publish this directory because it is outside `source/`.
